# Contributing

Issues and pull requests are welcome. Please search existing issues first, create a GitHub fork, make focused changes and run `./gradlew clean build` with JDK 17 before opening a pull request.

By submitting a contribution, you agree to the contribution terms in [LICENSE](LICENSE), including the grant that allows JarException to incorporate and publish accepted changes in official AdvancedSoundAddon releases.

Forks are for development and contribution. Do not publish JAR files, packages, releases or independent distributions from a fork.
